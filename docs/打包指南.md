# 打包 Android APK

桌面端 exe 已经打包好并可用（见 [环境搭建.md](环境搭建.md) 与 `scripts/build_desktop.py`）。
本文只讲 **Android APK**。

---

## 先说结论：为什么在受限环境里打不出来

本项目的开发环境（DSH 的 workspace-write 沙箱）里**无法**构建 APK，原因是硬性边界：

```
Dart（Flutter 的运行时）无法派生子进程：
  Process.runSync('cmd', ['/c','echo','hi'])   → 拒绝访问 (CreateFile failed 5)
  Process.runSync('git', ['--version'])        → 拒绝访问
  Process.start(..., inheritStdio)             → 拒绝访问
```

而 PowerShell 在同一个环境里跑 `git` 是成功的 —— 所以问题不是 git、不是路径、
不是权限配置，而是**沙箱禁止 Dart 创建子进程**。

Flutter 构建 Android 的每一步都依赖派生子进程（取版本号要跑 `git log`、
编译 Dart、跑 Gradle），因此 `flet build apk` 在这个沙箱里不可能成功。

**在正常电脑上没有这个限制**，按下面步骤操作即可。

---

## 一、最快路径：用已经备好的工具链

开发过程中我已经把工具链下载解压到了 `.toolchain/`（约 3.5 GB），
并且把项目内的脚本改成了**自动适配**：

* 如果你的 `%APPDATA%` 可写 → 按标准方式构建，不做任何重定向；
* 如果不可写 → 自动把 Flutter / Gradle / Pub 的缓存重定向到 `.toolchain/`。

所以在你的电脑上只需要三步：

```powershell
cd D:\project\save-money-app

# 1) 安装 Android 平台包与构建工具（约 300MB，需要联网）
.venv\Scripts\python.exe scripts\setup_android_toolchain.py

# 2) 检查工具链
.venv\Scripts\python.exe scripts\setup_android_toolchain.py --check

# 3) 打包 APK（首次会下载 Gradle 依赖，可能 10~30 分钟）
.venv\Scripts\python.exe scripts\build_apk.py
```

跑完在 `build\apk\app-release.apk`。传到手机安装即可（需允许"安装未知来源应用"）。

### 已经放在 `.toolchain/` 里的东西

| 组件 | 版本 | 位置 |
| --- | --- | --- |
| Flutter SDK | 3.35.4 stable | `.toolchain/flutter` |
| JDK | OpenJDK 17.0.2 | `.toolchain/jdk17/jdk-17.0.2` |
| Android cmdline-tools | 11076708 | `.toolchain/android-sdk/cmdline-tools/latest` |

> 这是**便携式**工具链：整个 `.toolchain` 目录可以拷到别的机器继续用。
> 不需要的话直接删掉，按下面的"标准路径"自己装也行。

### 如果构建卡住

脚本会自己处理这几个坑（都有注释记录）：

| 症状 | 原因 | 脚本的处理 |
| --- | --- | --- |
| `flutter` 无限重建工具快照（cache 里出现 `flutter_tools.snapshot.old1..40`） | `%APPDATA%` 不可写，Flutter 写不了 `.flutter_tool_state` | 自动把 `APPDATA`/`USERPROFILE` 重定向到 `.toolchain/userprofile` |
| `CreateFile failed 5` + `git log` 失败 | `USERPROFILE` 指向不存在的目录，git 读不到 `.gitconfig` | 自动创建该目录并写入最小 git 配置 |
| 下载 Gradle 卡死/超时 | `services.gradle.org` 在国内常超时 | `build_apk.py` 会把 Flutter 里的下载地址换成腾讯云镜像 |

## 二、标准路径：用自己的环境

如果你更愿意用自己装的工具，需要：

| 依赖 | 版本要求 | 说明 |
| --- | --- | --- |
| Flutter SDK | 3.24+ | 解压后把 `flutter\bin` 加入 PATH |
| JDK | 17（必须） | 设 `JAVA_HOME` |
| Android SDK | API 34 或 35 | 设 `ANDROID_HOME`，需含 `platform-tools`、`platforms;android-3x`、`build-tools;3x.0.0` |
| flet-cli | 与 flet 同版本 | `.venv\Scripts\python.exe scripts\install_deps.py flet-cli==0.28.3` |

然后：

```powershell
# 安装 Android 平台包
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" `
    "platform-tools" "platforms;android-35" "build-tools;35.0.0"
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" --licenses

# 打包
cd D:\project\save-money-app
.venv\Scripts\python.exe -m flet build apk apps\mobile `
    --project flipped_piggy --org com.flipped `
    --product "Flipped的存钱罐" --build-version 1.0.0
```

（`scripts/build_apk.py` 做的就是这件事，只是额外处理了缓存重定向和 Gradle 镜像。）

## 三、打包参数说明

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `--project` | `flipped_piggy` | Android 包名后缀，最终包名 `com.flipped.flipped_piggy` |
| `--org` | `com.flipped` | 组织标识 |
| `--product` | `Flipped的存钱罐` | 应用显示名（手机桌面上的名字） |
| `--build-version` | `1.0.0` | 版本号 |
| 图标 | `assets/icon.png` | Flet 打包默认读取，已由 `prepare_brand_icon.py` 生成 |

想改包名/组织，改 [scripts/build_apk.py](scripts/build_apk.py) 顶部的
`PROJECT_NAME` / `ORG` 两个常量。

## 四、手机端与桌面端的差异

界面代码完全共用（`apps/_shared`），只有这些不同：

| 项目 | 桌面端 | 手机端 |
| --- | --- | --- |
| 入口 | `apps/desktop/app_entry.py` | `apps/mobile/app_entry.py` |
| 窗口 | 420×860 可缩放窗口 | 全屏 |
| 内容宽度 | 跟随窗口 | 跟随屏幕 |
| 数据目录 | `%APPDATA%\SaveMoneyApp`（不可写时自动回退，见下） | 应用私有目录 |

**数据目录回退链**（`core/utils/paths.py`）：首选目录不可写时会依次尝试
本地数据目录 → 用户主目录 → 系统临时目录，并给用户一个人话提示框。
这样即使系统权限受限，应用也不会"打不开"。

---

## 五、装到手机后

* 数据存在应用私有目录，卸载会一起删掉；
* 换手机时用 **设置 → 数据备份 → 导出数据库(.db)**，在新手机
  **设置 → 数据备份 → 导入备份** 恢复；
* 手机端和桌面端的数据是**各自独立**的，靠上面的备份文件互相迁移。

## 六、常见问题

**Q：`flutter doctor` 报一堆红叉？**
本文的构建只需要 Android toolchain 那一项。跑
`.venv\Scripts\python.exe scripts\build_apk.py --check` 看本项目实际需要的三项
（JDK / Flutter / Android SDK）是否齐备即可。

**Q：构建报 `Could not resolve all files for configuration`？**
Gradle 依赖下载失败，多半是网络。在 `android/gradle.properties` 里加国内镜像，
或者重试（Gradle 会断点续传）。

**Q：APK 装到手机提示"解析包错误"？**
多半是 `minSdkVersion` 高于手机系统版本。Flet 默认 minSdk 21（Android 5.0），
一般没问题；老机器可在 `pyproject.toml` 里调。

**Q：能直接产出 iOS 版吗？**
`flet build ipa` 在 **macOS** 上才能跑，且需要 Apple 开发者账号签名。
本项目按需求只做 Windows 桌面端 + Android。

## 🟡 第二阶段 · 稳定后迭代

### 1. 预算管理

**目标**：给每个支出分类设月度预算，首页显示剩余额度，超支橙红提醒。

- 数据库已预留 `budgets (category_id, year_month, amount)`，无需改结构
- 待做：
  - `core/services/budget_service.py`：预算设置、已用/剩余、超支比例
  - 设置页：分类预算设置入口（按月）
  - 首页：预算剩余卡片、进度条、超支用 `theme.WARNING` 色
  - `core/db/repositories/budget_repo.py`：预算增删改查

### 2. 统计图表

**目标**：月度支出饼图、存款增长折线图。

- Flet 自带 `ft.PieChart` / `ft.LineChart` / `ft.BarChart`，无需第三方库
- 数据已就绪：`stats_service.category_breakdown()`、`stats_service.cumulative_savings_trend()`
- 待做：
  - 新增 `views/stats.py` 统计页（或放在首页下方可折叠区）
  - 饼图：按分类支出占比；折线图：累计存款增长
  - 图表配色统一从 `theme.py` 取，保证明暗主题下都清晰

### 3. 本地密码锁

**目标**：打开软件需要验证密码，密码哈希保存，不存明文。

- 数据库已预留 `settings` 表键位 `password_hash` / `password_salt`，无需改结构
- 待做：
  - `core/services/auth_service.py`：`hashlib.pbkdf2_hmac` 加盐哈希、校验、修改密码
  - 启动时先显示解锁页，验证通过才进主界面
  - 设置页：开启/关闭密码锁、修改密码
  - 注意：忘记密码无法找回（本地应用），界面上要明确提示

### 4. 模板录入

**目标**：工资等固定收支一键记账。

- 数据库已预留 `templates` 表，无需改结构
- 待做：
  - `core/db/repositories/template_repo.py`
  - 记一笔页面：模板快捷按钮，点击后自动填好金额/分类/备注
  - 设置页：模板增删改
  - 可选：到期提醒（本月还没记工资时首页提示）

## 有意没做的事（避免过度设计）

| 没做 | 原因 |
| --- | --- |
| 云同步 | 需求是本地优先 + 备份迁移；云同步涉及账号体系与服务器成本 |
| 多币种 | 记账场景里极少用，汇率维护成本高 |
| 导入银行流水 | 各家格式不一，且需要清洗规则，性价比低 |
| 复式记账 | 对个人记账过重，用户理解成本高 |

---

## 每次迭代的固定动作

1. 先写 / 改 `core/services` 里的业务逻辑，并在 `tests/` 加用例；
2. 跑 `tests/run_tests.py` 确认算钱逻辑正确；
3. 再改界面（`apps/_shared`）；
4. 跑 `scripts/check_ui.py` 与 `scripts/check_dialogs.py`；
5. 改过数据库结构的话，提升 `SCHEMA_VERSION` 并补 `MIGRATIONS`；
6. 更新本文档与 `README.md` 的功能清单。

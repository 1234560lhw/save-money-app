# 环境搭建与打包

本文记录本项目从零搭环境的完整过程，以及踩到的坑和解决办法。

---

## 1. 环境选型

| 项目 | 选择 | 原因 |
| --- | --- | --- |
| Python | 3.12.10 | Flet 0.28.x 支持良好的版本 |
| UI 框架 | Flet 0.28.3 | 一套 Python 代码可同时出桌面程序和 Android APK，自带 Material 组件与热重载 |
| 数据库 | 标准库 `sqlite3` | 单文件、免安装、跨设备直接拷贝文件迁移 |
| 金额计算 | 标准库 `decimal` | 避免 float 误差，记账软件必需 |
| 密码哈希 | 标准库 `hashlib` | 第二阶段密码锁用，无需第三方库 |
| 虚拟环境 | 项目内 `.venv/` | 与系统 Python 隔离，换机器不污染全局 |

**关于 Flet 版本**：Flet 已有 1.0.x 版本，但 API 与 0.2x 系列不兼容，
大量文档与打包链仍以 0.2x 为准，因此本项目锁定 `flet==0.28.3`。
将来升级 1.0 需要同步调整 `apps/_shared/` 下的控件写法。

---

## 2. 从零搭建

```powershell
cd D:\project\save-money-app

# 1) 创建专用虚拟环境
python -m venv .venv

# 2) 安装运行依赖（走清华镜像，见 config/pip.ini）
.venv\Scripts\python.exe scripts\install_deps.py -r requirements-desktop.txt

# 3) 验证
.venv\Scripts\python.exe tests\run_tests.py          # 业务逻辑测试
.venv\Scripts\python.exe scripts\check_ui.py         # 页面能正常构建
.venv\Scripts\python.exe scripts\check_dialogs.py    # 弹窗交互正常
```

`requirements.txt` 只有 `flet`；`requirements-desktop.txt` 额外包含
`flet-desktop`（原生窗口）和 `flet-web`（浏览器预览）。

---

## 3. 依赖说明

| 包 | 用途 |
| --- | --- |
| `flet` | Python 端 UI 框架 |
| `flet-desktop` | 桌面窗口客户端（首次以窗口方式运行时 Flet 会自动下载） |
| `flet-web` | 浏览器预览客户端（`--web` 模式需要） |

这三者版本必须一致，否则客户端与 Python 端协议不匹配，会出现白屏或连不上。

---

## 4. 国内网络：使用镜像

`config/pip.ini` 已配置清华 TUNA 镜像：

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
extra-index-url = https://pypi.org/simple
```

让 pip 使用它（任选一种）：

```powershell
# 方式一：临时指定
$env:PIP_CONFIG_FILE = "D:\project\save-money-app\config\pip.ini"

# 方式二：直接加参数
.venv\Scripts\python.exe -m pip install flet==0.28.3 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 5. 踩到的坑与解决办法

### 5.1 `python -m venv .venv` 报 ensurepip 失败

**现象**

```
PermissionError: [Errno 13] Permission denied: '...\Temp\...\pip-25.0.1-py3-none-any.whl'
```

**原因**：`ensurepip` 和 `pip install` 都会先用 `tempfile.mkdtemp()` 建临时目录。
在受限沙箱/受限权限环境下，Python 以 mode `0o700` 创建的目录会得到一张很严的
Windows ACL，随后往里写文件就被拒绝。

**解决**：项目自带补丁 `core/utils/tempfix.py`，把 `tempfile.mkdtemp` 换成
以 `0o777` 创建目录（权限可继承），并用 `scripts/install_deps.py` 安装依赖。

```powershell
# 自检补丁是否生效
.venv\Scripts\python.exe core\utils\tempfix.py
```

`scripts/install_deps.py` 还会离线把 pip 引导进 `.venv`（用宿主 Python 自带的
pip wheel 解包），因此不依赖网络也能修好环境。

### 5.2 运行时报 "Installing flet-desktop package..."

Flet 首次以桌面窗口方式运行时会尝试自己 `pip install flet-desktop`。
同样受临时目录限制会失败，表现为**窗口打不开**。

**解决**：预先显式安装，见上面第 2 步。`flet-web` 同理。

### 5.3 中文乱码

Windows 控制台默认 GBK。程序启动时统一把 stdout/stderr 切到 UTF-8
（`core/bootstrap.py` 的 `enable_utf8_console()`），CSV 导出用 `utf-8-sig`，
Excel 双击打开不乱码。

### 5.4 数据库文件位置

默认在系统用户数据目录；开发和测试时可以用环境变量改到别处：

```powershell
$env:SAVE_MONEY_DATA_DIR = "D:\project\save-money-app\.devdata"
$env:SAVE_MONEY_DB_FILE  = "D:\project\save-money-app\.devdata\pocket_money.db"
```

或直接用 `--dev` 参数（等价于把数据放到 `.devdata/`）。

## 6. 打包成独立软件

打包用的工具不进运行依赖，需要时单独装：

```powershell
.venv\Scripts\python.exe scripts\install_deps.py flet-cli
```

### 6.1 Windows 桌面版

```powershell
.venv\Scripts\python.exe -m flet build windows apps\desktop
```

产出在 `build\windows\`，双击 exe 即可运行，数据库仍放在 `%APPDATA%\SaveMoneyApp`。

### 6.2 Android APK

```powershell
.venv\Scripts\python.exe -m flet build apk apps\mobile --project "save_money" --org "com.yourname"
```

**前置条件**（首次打包比较折腾，需要能联网下载 Flutter SDK 与 Android 工具链）：

* JDK 17+
* Android SDK（`ANDROID_HOME` / `ANDROID_SDK_ROOT` 指向 SDK 目录）
* 首次运行 `flet build` 会自动拉取 Flutter SDK，网络慢时可以配置镜像

打包产物在 `build\apk\`，安装到手机即可。手机端数据存在应用私有目录，
换机时用「设置 - 数据备份 - 导出数据库」再在新机导入。

## 7. 日常开发命令速查

```powershell
# 热重载开发（桌面窗口；改完代码自动重启）
.venv\Scripts\python.exe scripts\dev_run.py

# 浏览器预览（手机端布局）
.venv\Scripts\python.exe scripts\dev_run.py --target mobile --web

# 造演示数据
.venv\Scripts\python.exe scripts\demo_data.py --reset

# 业务逻辑测试（纯数据）
.venv\Scripts\python.exe tests\run_tests.py -v

# 界面 / 弹窗自检（无头，不需要开窗口）
.venv\Scripts\python.exe scripts\check_ui.py -v
.venv\Scripts\python.exe scripts\check_dialogs.py
```
